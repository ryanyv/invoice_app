# سیستم جامع صدور پیش‌فاکتور و مدیریت قیمت (Pipecal Pro 2.0)

نسخه جدید، بازنویسی شده از صفر با معماری مدرن **React + TypeScript + Tailwind CSS + Electron** برای سیستم‌عامل‌های **macOS** و **Windows**.

---

## 🌟 ویژگی‌های کلیدی سیستم جدید

1. **مدیریت کامل قیمت‌ها در درون نرم‌افزار (بدون نیاز به ویرایش دستی فایل‌ها):**
   - **نرخ پایه لوله‌ها:** تغییر نرخ هر کیلوگرم پلی‌اتیلن (PE100, PE80, PE63) با اعمال آنی در پیش‌فاکتورها.
   - **کاتالوگ اتصالات:** جدول داده‌ای هوشمند با قابلیت **ویرایش سریع قیمت درون جدول (Inline Edit)** برای تمام ۲۵۴ اتصال استاندارد.
   - **افزایش/کاهش درصدی گروهی:** امکان تغییر درصدی قیمت‌ها (مثلاً افزایش ۱۰٪ به دلیل نوسان بازار) روی کل کاتالوگ یا یک دسته‌بندی خاص با یک کلیک.
   - **افزودن و حذف اتصالات:** افزودن آسان کالاها و سایزهای جدید به همراه تعداد در بسته.
   - **خروجی و ورودی اکسل (CSV):** دانلود کاتالوگ به صورت CSV جهت ویرایش در Excel و بارگذاری مجدد به سیستم.

2. **صدور پیش‌فاکتور حرفه‌ای (طراحی بومی راست‌به‌چپ RTL):**
   - پشتیبانی ۱۰۰٪ طبیعی از فونت‌های فارسی (وزیرمتن) و تقویم جلالی/شمسی بدون باگ‌های قدیمی ReportLab.
   - فرم تعاملی محاسبه لوله: همگام‌سازی دوطرفه بین متراژ (Length) و وزن (Mass) بر مبنای استانداردهای وزنی DIN.
   - انتخاب هوشمند اتصالات با منوهای آبشاری (نوع، محصول، فشار کاری، سایز و استعلام آنی قیمت واحد).
   - محاسبه خودکار پله‌های تخفیف یا اعمال تخفیف مبلغی دلخواه.
   - اعمال ارزش افزوده (۱۰٪ یا نرخ سفارشی).
   - تبدیل خودکار مبلغ نهایی به حروف فارسی.

3. **چاپ و خروجی PDF با کیفیت عالی:**
   - صفحه استاندارد A4 افقی (Landscape) منطبق با سربرگ رسمی شرکت پلی غرب و لوگو.
   - صدور مستقیم PDF یا ارسال به پرینتر سیستم‌عامل.

4. **سوابق فاکتورها و پشتیبان‌گیری:**
   - آرشیو تمام پیش‌فاکتورهای صادر شده همراه با جستجو بر اساس نام مشتری، شماره فاکتور یا تلفن.
   - شماره‌گذاری ترتیبی و خودکار پیش‌فاکتورها.
   - تهیه نسخه پشتیبان کامل (Backup JSON) و بازیابی آسان.

## 🚀 راهنمای اجرا و توسعه

### پیش‌نیازها
- **Node.js** نسخه 18 یا بالاتر
- **npm**

### اجرای نسخه تحت وب (جهت بررسی سریع در مرورگر):
```bash
npm run dev
```
سپس مرورگر را در آدرس `http://localhost:5173` باز کنید.

### اجرای نسخه دسکتاپ (Electron):
```bash
npm run electron:dev
```

---

## 📦 نحوه ساخت بسته نصبی (Build & Packaging)

### ساخت برای سیستم‌عامل مک (macOS):
```bash
# ساخت نرم‌افزار آماده اجرا (Unpacked App):
npm run electron:pack

# خروجی در مسیر:
release/mac-arm64/Pipecal Pro.app
```

### ساخت فایل نصبی ویندوز (Windows .exe / .msi):
```bash
npm run electron:build:win
```

## 📂 ساختار فایل‌های پروژه

- `src/components/InvoiceBuilder/` — فرم صدور پیش‌فاکتور و محاسبات زنده اقلام
- `src/components/PriceManager/` — پنل مدیریت قیمت‌های پایه، کاتالوگ و تغییرات گروهی
- `src/components/InvoicePrint/` — صفحه چاپ سربرگ‌دار و خروجی PDF
- `src/components/InvoiceHistory/` — سوابق و آرشیو فاکتورها
- `src/services/calculator.ts` — موتور محاسبات فنی (وزن بر اساس DIN، SDR، متراژ، قیمت و تخفیف)
- `src/services/storage.ts` — مدیریت پایگاه داده محلی، فایل‌های پشتیبان و CSV
- `src/services/persianUtils.ts` — تبدیل تاریخ شمسی، اعداد و حروف فارسی
- `electron/` — اسکریپت‌های پردازش اصلی و یکپارچه‌سازی با سیستم‌عامل
